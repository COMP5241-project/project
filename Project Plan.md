## Team Work Breakdown

*   **Member 1 (Backend Architecture & Database):** Build the core independent technical infrastructure using Python, FastAPI, and SQLite to support course generation and data storage[cite: 1]. This role focuses heavily on producing tangible technical outputs.
*   **Member 2 (AI Orchestration & Prompt Engineering):** Configure the AI prompts and workflows to dynamically adjust content depth, ensuring material is engaging for non-CS majors while remaining rigorous for CS graduates[cite: 1].
*   **Member 3 (Interactive Learner Experience):** Develop the frontend UI to host diverse content formats, including interactive roleplays, simulations, AI-narrated animations, and online coding environments[cite: 1].
*   **Member 4 (Instructor & Analytics Portal):** Build the dashboard allowing instructors to manually or automatically customize existing mini-courses, import student rosters, and track participation metrics[cite: 1].
*   **Member 5 (Domain Expansion & UX Research):** Implement the self-learning path generator for external subjects[cite: 1], synthesize development trends from social media[cite: 1], and lead user testing to refine the platform.

## Technical Execution & AI Collaboration

*   Leverage AI coding agents for rapid feature development and testing, prioritizing human judgment in framing problems and specifying requirements over manual syntax writing[cite: 1].
*   Document how the AI implements solutions under the hood, clearly mapping out the system architecture and learning new skills continuously[cite: 1].
*   Refine the prototypes iteratively based on direct feedback collected from stakeholders and users[cite: 1].

## Validation & Final Delivery

*   Unify individual feature branches into one final collaborative app that demonstrates sufficient complexity and clear contributions from all five members[cite: 1].
*   Structure the final presentation to explicitly detail how the team applied Anthropic’s 4D AI Fluency framework (Delegation, Description, Discernment, Diligence) throughout the project lifecycle[cite: 1].
