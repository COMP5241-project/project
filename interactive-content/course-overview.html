Course overview · PolyU

COMP5241: Software Engineering in the Age of AI

This course introduces the principles and practices behind building reliable software, from understanding how AI is changing development to planning a lifecycle, collaborating with version control, using coding agents responsibly, and testing the result. The notes and interactive activities below provide a guided route through these topics.

5 chapters Notes in 6 languages Games and interactive demos

Course at a glance

What you will explore

The course connects software engineering foundations with practical, AI-aware development workflows.

Software development foundations

Understand the stages of the software lifecycle, from requirements and design through implementation, testing, deployment, and maintenance.

Effective collaboration

Use Git and GitHub concepts to manage changes, coordinate work, and maintain a dependable history as software evolves.

AI-assisted engineering

Work with coding agents using clear specifications and useful project context, while reviewing and verifying generated work.

Quality and testing

Choose appropriate test approaches, cover edge cases, and use feedback to improve confidence in the software you deliver.
